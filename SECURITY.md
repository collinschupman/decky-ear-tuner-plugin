# Security policy

## Supported versions

Ear Tuner has no published release yet. Security fixes currently target `main`.
When releases are published, this policy will identify the supported versions.
Passing automated checks does not establish Steam Deck release readiness.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues or discussions. Use
[GitHub private vulnerability reporting](https://github.com/collinschupman/decky-ear-tuner-plugin/security/advisories/new).
If that option is unavailable, email the maintainer at
[collinschupman@gmail.com](mailto:collinschupman@gmail.com).

Include the affected commit or version, reproduction steps, and potential
impact. Share only the information needed to reproduce the problem; remove
credentials, recordings, personal information, and unrelated logs.

The sole maintainer reviews reports as availability permits. There is no
guaranteed response time or bug bounty. Please coordinate public disclosure with
the maintainer so a fix and advisory can be prepared.
